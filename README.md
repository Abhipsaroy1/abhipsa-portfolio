# Portfolio Website

Static portfolio for **Abhipsa Roy Choudhury** with:
- Profile summary
- Project and experience sections
- Downloadable Resume and certification PDFs

## Local preview

Open `index.html` directly in your browser, or run a local server:

```powershell
cd c:\Portfolio
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Make it accessible to recruiters

Deploy this folder to any static hosting platform:
- GitHub Pages
- Netlify
- Vercel

After deployment, share your public URL in applications and LinkedIn.
